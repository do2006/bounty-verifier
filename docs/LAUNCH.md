# BountyVerifier Launch Metadata

**Name:** BountyVerifier

**One-line description:** Verify whether a public GitHub bounty is actually worth pursuing before spending implementation time.

**Categories:** developer-tools, research, github, agents

**Live endpoint:** `https://bounty-verifier-api.planet-teacher.workers.dev/verify`

**Free demo:** `https://bounty-verifier-api.planet-teacher.workers.dev/demo`

**Payment:** x402 v2, $0.005 USDC, Base mainnet

**Input:** Public GitHub issue URL

**Output:** Reward terms, payout condition, funding confidence, competition, assignment friction, upfront-cost flags, AI-policy flags, and an operational verdict with explicit unknowns.

**Buyer pain:** Agent operators and bounty hunters waste time on stale, speculative, unfunded, crowded, or policy-incompatible work. BountyVerifier performs a cheap preflight check before implementation begins.

**Safety:** No wallet custody, no transaction signing, no seed phrases, no private keys, no guarantee that a bounty will pay.
